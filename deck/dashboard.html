Cohort Dashboard

A marking and follow-up tool for the 24 week programme. It does not host content, the PDFs do that. It answers four questions: where is everyone, what is waiting for me to mark, how do I mark it consistently, and who is about to disappear. Supabase Postgres behind it, ten tables, four screens.

Under the hood

Ten tables in Supabase Postgres, with row level security doing the authorisation so there is no custom API layer to maintain. One view, v_student_progress, powers the matrix, the KPIs and the flags. Students are learning this exact stack in weeks 5 to 8, so the tool doubles as a reference implementation.
